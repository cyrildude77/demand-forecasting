# demand-forecasting
# 📦 Demand Forecasting for Retail Inventory Optimization

## 📌 Business Problem
Retailers must decide how much inventory to stock each day.
Poor demand forecasts lead to:
- Stockouts (lost revenue)
- Overstocking (storage & wastage costs)

This project builds an end-to-end demand forecasting system to
predict daily sales at a store–item level.

---

## 🧠 Approach
1. Data validation & cleaning
2. Exploratory Data Analysis (trend & seasonality)
3. Feature engineering (lags, rolling statistics)
4. Baseline & classical models (Naive, SARIMA)
5. ML models (XGBoost)
6. Error analysis & business insights
7. Streamlit dashboard for stakeholders

---

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Scikit-learn
- XGBoost
- Statsmodels
- Streamlit
- Matplotlib

---

## 📊 Key Insights
- Strong weekly and yearly seasonality
- ML models outperform classical baselines
- Lag and rolling features are most predictive
- High-demand items show higher forecast variance
